
**IAM → Lambda → DynamoDB → API Gateway → SNS → S3**

A simple project is a **Contact/Feedback application**:

* User opens a website hosted in **S3**
* User enters **name, email, message**
* Website calls **API Gateway**
* API Gateway invokes **Lambda**
* Lambda saves the message in **DynamoDB**
* Lambda publishes a notification to **SNS**
* SNS sends an email notification to you

### Architecture

```text
                    USER
                      |
                      v
             +----------------+
             |   Amazon S3    |
             | HTML/CSS/JS    |
             +----------------+
                      |
                   HTTPS
                      |
                      v
             +----------------+
             |  API Gateway   |
             |   POST /contact|
             +----------------+
                      |
                      v
             +----------------+
             |    Lambda      |
             |  Python code   |
             +----------------+
                 /         \
                /           \
               v             v
      +---------------+   +---------------+
      |   DynamoDB    |   |      SNS      |
      | Store message |   | Email alert   |
      +---------------+   +---------------+
---

# PART 9 — Lambda Code

Open your Lambda function.

Go to:

```text
Code
→ lambda_function.py
```

Delete the existing code.

Put this in:

```python
import json
import uuid
import boto3
from datetime import datetime

dynamodb = boto3.resource("dynamodb")
sns = boto3.client("sns")

table = dynamodb.Table("ContactMessages")

SNS_TOPIC_ARN = "YOUR_SNS_TOPIC_ARN"


def lambda_handler(event, context):

    try:

        body = json.loads(event.get("body", "{}"))

        name = body.get("name")
        email = body.get("email")
        message = body.get("message")

        if not name or not email or not message:
            return {
                "statusCode": 400,
                "headers": {
                    "Content-Type": "application/json"
                },
                "body": json.dumps({
                    "message": "Name, email and message are required"
                })
            }

        message_id = str(uuid.uuid4())

        table.put_item(
            Item={
                "id": message_id,
                "name": name,
                "email": email,
                "message": message,
                "createdAt": datetime.utcnow().isoformat()
            }
        )

        sns.publish(
            TopicArn=SNS_TOPIC_ARN,
            Subject="New Contact Form Submission",
            Message=f"""
New contact form submission

Name: {name}
Email: {email}

Message:
{message}
"""
        )

        return {
            "statusCode": 200,
            "headers": {
                "Content-Type": "application/json",
                "Access-Control-Allow-Origin": "*"
            },
            "body": json.dumps({
                "message": "Message submitted successfully"
            })
        }

    except Exception as e:

        print(str(e))

        return {
            "statusCode": 500,
            "headers": {
                "Content-Type": "application/json",
                "Access-Control-Allow-Origin": "*"
            },
            "body": json.dumps({
                "message": "Internal server error"
            })
        }
```

Change:

```python
SNS_TOPIC_ARN = "YOUR_SNS_TOPIC_ARN"
```

to your actual SNS ARN.

For example:

```python
SNS_TOPIC_ARN = "arn:aws:sns:ap-south-1:123456789012:ContactNotifications"
```

Put this code inside:

```html
<!DOCTYPE html>
<html>

            width: 100%;

        }

        textarea {
            height: 150px;
        }

        button {
            padding: 12px 25px;
            cursor: pointer;
        }

        #result {
            margin-top: 20px;
        }
    </style>
</head>

<body>

    <h1>Contact Us</h1>

    <form id="contactForm">

        <input
            type="text"
            id="name"
            placeholder="Your name"
            required
        >

        <input
            type="email"
            id="email"
            placeholder="Your email"
            required
        >

        <textarea
            id="message"
            placeholder="Your message"
            required
        ></textarea>

        <button type="submit">
            Send Message
        </button>

    </form>

    <div id="result"></div>

    <script>

        const API_URL =
            "YOUR_API_GATEWAY_URL/contact";

        document
            .getElementById("contactForm")
            .addEventListener("submit", async function(event) {

                event.preventDefault();

                const data = {
                    name: document.getElementById("name").value,
                    email: document.getElementById("email").value,
                    message: document.getElementById("message").value
                };

                try {

                    const response = await fetch(API_URL, {
                        method: "POST",

                        headers: {
                            "Content-Type": "application/json"
                        },

                        body: JSON.stringify(data)
                    });

                    const result = await response.json();

                    document.getElementById("result").innerText =
                        result.message;

                } catch (error) {

                    document.getElementById("result").innerText =
                        "Something went wrong.";

                    console.error(error);
                }

            });

    </script>

</body>
</html>
```

Change:

```javascript
const API_URL =
    "YOUR_API_GATEWAY_URL/contact";
```

For example:

```javascript
const API_URL =
    "https://abc123.execute-api.ap-south-1.amazonaws.com/contact";
```

# PART 23 — Configure S3 Permissions

Go to:

```text
Permissions
```

You may see:

```text
Block public access
```

For this simple public website, you'll need to adjust the relevant Block Public Access settings.

**Be careful here:** making an S3 bucket public means its objects can be accessed by anyone who knows the URL. Do not put passwords, API keys, private documents, or secrets in this bucket.

Then add a bucket policy allowing public `GetObject`.

Use:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicRead",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
    }
  ]
}
```

Replace:

```text
YOUR_BUCKET_NAME
```

with your actual bucket name.

For example:

```json
"Resource": "arn:aws:s3:::my-contact-app-2026-12345/*"
```

Save the policy.

# PART 27 — What each service is doing

This is important for understanding the project.

| AWS Service     | Purpose                                     |
| --------------- | ------------------------------------------- |
| **IAM**         | Gives Lambda permission to use AWS services |
| **S3**          | Hosts your HTML/CSS/JavaScript              |
| **API Gateway** | Provides the public API endpoint            |
| **Lambda**      | Runs your backend Python code               |
| **DynamoDB**    | Stores contact messages                     |
| **SNS**         | Sends notification email                    |

So if you're explaining this project in an interview:

> **S3 hosts the frontend. API Gateway exposes the REST/HTTP endpoint. Lambda processes the request. DynamoDB stores the submitted data. SNS sends a notification. IAM provides the required permissions.**

# PART 30 — Important Free Tier precautions

Since you specifically want a **free-tier learning project**, I recommend these settings:

### Lambda

Use:

```text
128 MB
```

No provisioned concurrency.

Lambda currently provides 1 million requests and 400,000 GB-seconds of monthly free usage. ([Amazon Web Services, Inc.][2])

### API Gateway

Use:

```text
HTTP API
```

rather than REST API for this simple project.

The current API Gateway pricing page lists 1 million HTTP API calls/month in its Free Tier for qualifying new customers for up to 12 months. ([Amazon Web Services, Inc.][8])

### DynamoDB

For this tutorial, keep the table tiny and don't enable unnecessary features such as:

```text
Point-in-time recovery
Global tables
DAX
Large backups
```

DynamoDB's current free tier includes 25 RCUs, 25 WCUs and 25 GB of storage for Standard tables. ([Amazon Web Services, Inc.][5])

### SNS

Use:

```text
Email
```

**Do not use SMS** for this tutorial.

SNS currently provides a free allowance for email notifications, while SMS pricing varies by destination. ([Amazon Web Services, Inc.][3])

### S3

Keep only:

```text
index.html
```

in the bucket.

Don't upload large videos, backups, databases, etc.

S3 charges according to storage, requests, transfer and other usage, so keeping the demo tiny minimizes the possibility of charges. ([Amazon Web Services, Inc.][7])
